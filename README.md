# RYStore Retail Sales & Performance Analysis

## Project Name
RYStore Retail Sales & Performance Analysis

## Project Idea
An end-to-end retail data analysis project on the RYStore dataset to uncover revenue and profit trends, evaluate product category and branch performance, and understand customer purchasing behavior. **Power BI** (with **Power Query** for data cleaning and DAX modeling) and **Tableau** serve as the core of the project for building comprehensive interactive dashboards, supported by **SQL** for database querying and **Excel & Python** for supplementary data exploration.

Dataset: https://github.com/ryanariefe/RYStore-Retail-Dataset
